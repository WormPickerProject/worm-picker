# Contributing to *worm-picker*

> **Important** — External contributions are **not** accepted.  
> Only authorised Fang-Yen-Lab personnel may contribute, subject to the
> licence terms in *LICENSE*.

---

## 1  Scope of Permitted Contributions

| Contributor Class | Permitted Actions | Ownership of Contributions |
|-------------------|------------------|----------------------------|
| **Fang-Yen-Lab members** | • Fork / branch within Lab-controlled repositories<br>• Modify or extend code for internal, non-commercial research | Lab owns copyright *in its own modifications* (see § 4 of LICENSE). |
| **All other parties** | No access, no copying, no modification, and no pull requests | — |

Any contribution made by an unauthorised individual will be rejected without
review.

---

## 2  Development Rules for Fang-Yen-Lab Members

1. **Version Control**  
   - Work in feature branches named `<feature>/<short-description>`  
   - Write clear, concise commit messages in the imperative mood  
   - Open pull requests only after passing all tests

2. **Coding Standards**  
   - Follow the existing code style; run the project’s formatter and linters  
   - Use descriptive identifiers and inline comments for complex logic  
   - Avoid sweeping architectural changes without prior discussion

3. **Documentation**  
   - Provide docstrings for all new functions, classes, and modules  
   - Update *README* and other user guides when adding or altering features
